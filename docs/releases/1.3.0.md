# MyArad 1.3.0

Android direct-download release, versionCode 8, signed with the original key.

- Event cards show the organiser's program, never the RSS publication date.
  Publication dates remain labelled in opened article details.
- Explicit organiser dates with years support calendar filtering, overlapping
  ranges and running/upcoming classification. Missing years are not invented.
- Signed-in account buttons match the sign-in button; narrow headers truncate
  long names and retain usable controls.
- Includes the supplied Vasile wizard portrait and existing navigation fixes.

Validation includes date/feed/filter regression tests, lint, typecheck, browser
checks and an upgrade installation in the Android emulator. Physical phones
require separate validation.

Distribution is a signed APK, not a Play Store submission. The current service
still depends on the laptop backend and a temporary Cloudflare hostname.
Closed-app FCM notifications remain unconfigured; external-source RSVP is not
implemented. Community-event attendance remains available.
